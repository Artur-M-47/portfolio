# 🚗📝 Project: Insurance Marketing Campaigns with Predictive Modeling (Kaggle Challenge s4e7)

The objective of this project, based on the **Kaggle Playground Series - Season 4, Episode 7** challenge, was to build a robust machine learning classification model to predict which customers are most likely to respond positively to an automobile insurance offer. This aims to optimize marketing spend and improve campaign conversion rates.

The primary goal was to maximize the model's ability to rank positive responses higher than negative ones.

**Evaluation Metric:** Submissions were evaluated using the **Area Under the ROC Curve (ROC AUC)**, which is crucial for maximizing performance on highly imbalanced datasets.

## 🔍 Project Overview & Methodology

### 🛠️ Data Preprocessing and Feature Engineering
The dataset exhibited a severe **class imbalance** (approx. 12.7% positive responses), guiding the choice of evaluation metrics and modeling techniques.

* **Binary Transformation:** Categorical columns like `Gender`, `Vehicle_Damage`, and `Previously_Insured` were converted into integer/boolean types for memory efficiency.
* **One-Hot Encoding (OHE):** Applied to the combined training/validation data for use with standard tree-based models (Random Forest, XGBoost), expanding the feature set.
* **Categorical Type Conversion:** Categorical features were converted to the native `category` dtype for models with inherent categorical handling (LightGBM, CatBoost).

### 🧠 Modeling Strategy
A multi-tier modeling approach was employed for comparison, focusing on ensemble methods:

1.  **Model Comparison Baseline:** **Random Forest**, **XGBoost**, and **LGBM** Classifiers were benchmarked using the OHE or native categorical data preparation.
2.  **Advanced Model:** **CatBoost Classifier** was selected for deep tuning due to its native handling of categorical features and state-of-the-art performance potential.
3.  **Hyperparameter Tuning:** A manual grid search was performed on CatBoost (tuning `learning_rate`, `depth`, and `l2_leaf_reg`) using GPU acceleration (`task_type='GPU'`) and **Logloss** for early stopping.
4.  **Metric Alignment:** Although Logloss was used for optimization, the final model was selected and validated purely on **ROC AUC** to align with the competition's objective.

### 📊 Final Robust Validation: Stratified K-Fold Ensembling
To maximize generalization and score stability, the final prediction was generated using a **Stratified K-Fold (SKF) Ensembling** technique ($N=2$ Folds) with the best-tuned CatBoost parameters:

* **Stratification:** Ensured the severe class imbalance was evenly maintained across all training and validation folds.
* **Ensembling:** The final submission probability was calculated as the **mean of the predictions** generated by the model from each individual fold ($\text{test\_preds.mean(axis=1)}$), which effectively reduces model variance.
